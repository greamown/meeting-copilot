# Configuration

Compose configures internal service discovery:

```text
MC_STT_WORKER_URL=http://stt-worker:8001
MC_CODEX_WORKER_URL=http://codex-worker:8002
MC_TTS_WORKER_URL=http://optional-tts-worker:8003
MC_REDIS_URL=redis://redis:6379/0
```

The worker token and PostgreSQL password are generated by `scripts/docker_up.sh` and mounted from `runtime/secrets`. Do not place their values in Compose YAML, application settings, logs, or provider records.

Provider records contain public model settings and environment-variable secret references only. Repository context requires a Compose override that mounts a host path read-only into both the required worker and an `MC_REPOSITORY_ROOTS` allowlisted container path.

The persisted language matrix has independent values for UI, meeting input, secondary input, transcript display, translation, suggestion output, summary output, export, and TTS. Meeting preparation copies these defaults into the meeting record so later global setting changes do not silently change an active or historical meeting. Translation is optional and uses Codex CLI through the isolated worker; original transcript text is retained.
