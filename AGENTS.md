# Project instructions

- Codex CLI is the only LLM reasoning engine. Do not add another chat LLM API.
- Never store or log API keys, authorization headers, cookies, OAuth tokens, or Codex credential files.
- Preserve SQLite one-command development and localhost binding.
- Prefer local faster-whisper on CUDA and keep the explicit CPU fallback.
- Run backend tests and frontend type/build tests for every functional change.
